# 脚本结构模板（Script Structures）

拆解时用来"对号入座"，写脚本时用来"照着套"。每条都含时间轴分段 + 每段编导作用。

---

## 一、通用带货口播结构（电商/摆摊/直播间切片）

```
[0-3s]   钩子：反差/悬念/痛点，一句话留人
[3-15s]  冲突或异议抛出：替观众说出心里的疑问
[15-45s] 价值塑造：工艺/产地/年份/故事/原料
[45-55s] 社会认同：老顾客回购、路人围观、销量
[55-70s] 价格锚点 + 顾虑消除：贵→换算成便宜
[70-90s] 促成转化：当场成交、下单引导
```

**编导逻辑**：钩子留人 → 异议前置建立信任 → 价值让"值这个价" → 社会认同从众 → 锚点改变价格感知 → 成交。

---

## 二、Problem-Solution（问题-解决方案，15-30s）

```
[0-3s]   钩子：直接抛问题
[3-10s]  放大痛点：为什么这个问题严重
[10-25s] 给方案：方法/产品/技巧
[25-30s] CTA：下一步做什么
```

**适合**：知识口播、工具测评、方法技巧、知识科普。

---

## 三、List Format（清单体，30-60s）

```
[0-3s]   钩子："X 件事让你 [结果]"
[3-50s]  逐条：每 5-8 秒一条
[50-60s] CTA
```

**适合**：涨粉钩子、干货合集、避坑指南。

---

## 四、Story Arc（故事弧，45-60s）

```
[0-3s]   钩子：预告结果（结果前置）
[3-15s]  铺垫：背景和赌注
[15-45s] 过程：发生了什么
[45-55s] 结局：结果
[55-60s] 启示/CTA
```

**适合**：个人故事、案例、见证、短剧。

---

## 五、带货双顾客结构（摆摊/探店/本地生活常见）

```
[0-3s]   钩子：反差/身份反转
[3-25s]  老顾客场景：社会认同 + 回购背书
[25-70s] 摊主话术：价值塑造 + 价格锚点
[70-90s] 新顾客场景：试吃→当场成交（从众转化）
```

**编导逻辑**：用两个顾客把"犹豫→下单"的完整心理路径演给观众看。

---

## 六、POV/Skit（视角/情景剧，15-30s）

```
[0-3s]   铺垫：文字覆盖设定场景
[3-25s]  表演：演一个可代入的情景
[25-30s] 反转/笑点
```

**适合**：幽默、共鸣、垂类社区。

---

## 七、Tutorial（教程，30-60s）

```
[0-3s]   钩子：先展示成品/结果
[3-8s]   概述："怎么做"
[8-50s]  步骤：快、清晰
[50-60s] 结果 + CTA
```

**适合**：教程、演示、技能教学。
